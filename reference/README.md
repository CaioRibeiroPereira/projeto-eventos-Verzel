# Reference

Material de referência para o projeto, separado do código-fonte.

- `design/` — prints, mockups, paletas de cores, referências visuais de UI/UX.
- `docs/` — requisitos, especificações, anotações, links importantes.
- `examples/` — trechos de código, projetos ou bibliotecas usados como exemplo.

Esta pasta não faz parte do build/deploy da aplicação — é só material de apoio.
